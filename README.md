A one-liner excuse for when the tests are green but the app does nothing.

## Entry

> At standup I said the tests are green. Nobody asked whether the app does anything, and I did not volunteer it.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` — the 110-character entry, UTF-8, no trailing newline.
